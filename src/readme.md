This directory contains all the source code for the project.

- `get_topk.py`: Handles data preparation.
- `new_attack.py`: Generates adversarial attacks.
- `evaluate.py`: Runs the evaluation pipeline and produces evaluation data.

The `hybridattack/` directory contains utility modules used throughout the project, including:

1. **Word Recoverer** – for recovering perturbed tokens.
2. **Semantic Helper** – for computing semantic similarity and related operations.
3. **Ranker Model Wrappers** – abstraction layers for interacting with ranking models.
